# Terceiros

O código original do KStruct é MIT, conforme LICENSE.

OOFEM é um projeto separado, mantido por seus autores, sob LGPL-2.1-or-later. O KStruct escreve arquivos de entrada e invoca um executável local escolhido pelo usuário. Cada pacote desktop inclui o executável, o texto da licença, o README do OOFEM, o arquivo ZIP com as fontes exatas e a receita de compilação na pasta `oofem/`. O manifesto registra o commit, as opções de compilação e os hashes.

- OOFEM — https://github.com/oofem/oofem
- Licença OOFEM — https://github.com/oofem/oofem/blob/v3.0/COPYING.LGPLv2.1
- React, Vite, Three.js, Zod e Lucide — licenças conforme pacotes e respectivos projetos.
- Tauri — MIT / Apache-2.0, conforme seus componentes.
- pdfmake — MIT. O gerador incorpora os arquivos Roboto do pacote, sob SIL Open Font License 1.1.
- Inter — SIL Open Font License, distribuída pelo pacote @fontsource-variable/inter.

A arte de Dédalo foi criada para o projeto OpenStruct e fornecida no contexto de criação do KStruct. O ícone vetorial da coluna é original desta implementação. SAP2000 é mencionado apenas como referência funcional de produto, sem afiliação.
